# Support

| Request | Channel |
|---|---|
| Report a bug | GitHub issue, using the Bug form |
| Propose a skill, hook, or rule | GitHub issue, using the Proposal form |
| Report a vulnerability | Private reporting — [SECURITY.md](SECURITY.md) |
| Any other matter | GitHub issue; select the closest form |

For installation failures, consult [docs/INSTALL.md](docs/INSTALL.md), "Troubleshooting," first.
